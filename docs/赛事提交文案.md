# 项目描述（赛事提交用，约1800字）

**多视角金融研究 Agent：事件驱动四因子投研智能体（昇腾原生算力）**

**一句话定位**：输入一个金融热点关键词，AI 自动完成"事件理解 → 产业链推理 → 候选股筛选 → 四因子评分 → 风险分析 → 研究报告"的完整投研闭环，并支持大模型自主调用金融工具进行研究（ReAct Agent 模式）。

**一、解决的业务痛点**

投研行业长期存在四个真实痛点：
1. 信息过载：研究员每天翻阅 20+ 数据源（新闻、公告、行情、研报），手工拼凑主题投资线索，耗时且易遗漏关键信息；
2. 事件传导难："政策 → 产业链哪个环节受益 → 哪些标的最相关"的判断依赖资深经验，新人难以复制，团队能力断层；
3. 结论不可复现：人工研究主观性强，缺乏统一评分框架，同一热点不同人的结论差异大，难以审计；
4. 报告产出慢：一份主题研报从选题到初稿通常需要 1-2 天，严重挤占研究员的复核与判断时间。

**二、解决方案与核心功能**

本系统针对上述痛点提供端到端自动化的研究助理能力：
- **事件解析**：输入热点（如"低空经济政策"），基于昇腾云大模型（GLM-5.2）自动识别事件类型、受益行业与关键词，并具备规则兜底，保证无网络时仍可运行；
- **产业链推理**：内置产业链规则库 + LLM 推理双通道，显式输出上中下游受益环节与传导逻辑，可追溯；
- **候选股筛选**：自动映射到东财概念板块，获取真实成分股（行情/财务/新闻）；
- **四因子评分**：事件/价值/成长/市场四个维度标准化评分，叠加风险等级（波动率/最大回撤/估值分位），输出综合排名；
- **研究报告生成**：自动生成结构化 Markdown 研报（事件解读/产业链分析/候选股与理由/风险提示/免责声明）；
- **ReAct Agent 模式**：大模型像研究员一样自主决策——实时调用行情/财务/新闻/风险等 10 个金融工具完成研究，每一步工具调用轨迹可追溯，失败自动降级，永不空手而归；
- **多视角页面**：事件分析、多因子分析、风险分析、研究报告、历史记录、策略回测、组合优化 7 大功能页，深色专业主题 UI。

**三、技术架构与昇腾原生算力**

- **昇腾云大模型**：事件解析/Agent 决策/报告生成调用昇腾云 LLM API（GLM-5.2 on Ascend），并内置调用预算控制与监控（成功率/延迟可视化）；
- **MindSpore 昇腾加速**：协方差矩阵与因子归一化采用昇腾原生框架 MindSpore 算子实现（ops.MatMul/ReduceMean），昇腾环境自动启用 NPU 加速；本机无 MindSpore 时自动降级 numpy（结果一致），保证开发与演示可运行；
- **可解释、可复现**：四因子得分、风险量化、工具调用轨迹全部可视化；离线模式下因子计算完全确定，配合 122 个单元测试（全离线 mock）保证结论可复现；
- **数据链路**：东财 curl_cffi 直连（绕 TLS 风控）+ 离线包兜底 + 联网新闻缓存，三级降级设计，页面永不崩溃；
- **可信回测**：买入持有策略 + 真实交易成本（佣金/印花税/滑点），基准收益按日期对齐，协方差按交易日对齐，杜绝指标虚高。

**四、性能与质量**

- 预置热点秒开（<1s），真实分析 1-4 分钟（受 LLM 响应影响，工具并行执行）；
- 昇腾云 LLM 单次调用均延迟约 1.7s，侧边栏实时统计；
- 122 个单元测试（Agent 工具层/编排器/回测费用/协方差对齐/昇腾模块），全离线确定性验证；
- 一键部署：提供昇腾环境一键部署脚本（deploy_ascend.sh）与 Windows 启动脚本（启动网站.cmd）。

**五、商业化展望**

- **落地场景**：券商/基金投研部、财经内容生产、个人投资者研究助理、高校金融实验室；
- **目标客户**：B 端（券商研究所、基金投研、财经媒体、财富管理机构）+ C 端（专业投资者、量化爱好者、财经创作者）；
- **商业模式**：SaaS 订阅（B 端席位/C 端主题）、开放 API（事件解析/因子计算/风险评分按调用计费）、私有化部署（昇腾一体机，数据不出域，满足金融合规）、内容合作（研报分发流量分成）；
- **竞争壁垒**：事件驱动产业链推理的领域知识 + 昇腾端侧部署能力 + 可解释的因子/风险框架（区别于通用大模型问答）。

**合规声明**：系统输出"研究参考"，不构成投资建议；数据来自公开渠道，仅供技术交流与学术研究。
