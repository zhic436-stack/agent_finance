# 演示录屏脚本（≤3分钟）

> 目标：3 分钟内完整展示"热点输入 → 事件解析 → 产业链推理 → 四因子分析 → 研究报告"全链路，突出昇腾云大模型 + 多因子框架 + 可解释研究。

---

## 第 1 步：首页 + 预置热点秒开（0:00-0:20，20秒）

| 操作 | 预期效果 | 话术 |
|---|---|---|
| 启动 `streamlit run ui/app.py`，打开首页 | 标题 + 4 个预置热点按钮 | "这是我们的事件驱动金融研究 Agent。左边四个预置热点，我们点开'低空经济'演示。" |
| 点击「低空经济」预置热点 | 跳转事件分析页，秒开（<3秒） | "预计算结果秒开，避免现场网络波动。" |

## 第 2 步：事件解析 + Agent 执行轨迹（0:20-0:50，30秒）

| 操作 | 预期效果 | 话术 |
|---|---|---|
| 展示 Agent 执行轨迹 | st.status 逐步状态：事件理解→产业链→数据→因子→风险→报告 | "Agent 模拟研究团队流程：先理解事件，再推理产业链，然后验证数据。" |
| 展示事件解析结果 | 事件类型/受益行业/关键词 | "系统识别出这是行业事件，受益行业包括低空经济、eVTOL、通航运营等。" |
| 展示产业链推理 | 整机制造→通航运营→空管系统→基础设施 | "关键能力：自动推理产业链传导路径。" |

## 第 3 步：四因子分析（0:50-1:40，50秒）

| 操作 | 预期效果 | 话术 |
|---|---|---|
| 切到「多因子分析」页 | 综合得分 Top5 + 排名图 + 雷达图 | "我们用四个视角验证：事件、价值、成长、市场，每个股票都有四因子得分。" |
| 点开单股详情 | 四因子雷达图 + 柱状图 | "比如这只，成长因子和事件因子突出，说明事件驱动逻辑强。" |
| 展示排名表格 | 全量表格：代码/名称/四因子/综合/风险 | "所有候选股可对比，综合分 = 事件30% + 价值25% + 成长25% + 市场20%。" |

## 第 4 步：风险分析（1:40-2:10，30秒）

| 操作 | 预期效果 | 话术 |
|---|---|---|
| 切到「风险分析」页 | 风险等级饼图 + 高风险列表 | "我们不仅给分数，还做风险识别：波动率、最大回撤、估值风险。" |
| 展示高风险标的 | 红色高风险卡片 | "高风险标的一目了然，这是研究参考的重要组成部分。" |

## 第 5 步：研究报告（2:10-2:50，40秒）

| 操作 | 预期效果 | 话术 |
|---|---|---|
| 切到「研究报告」页 | 完整 Markdown 报告（事件摘要+影响链+个股点评） | "最终输出一份可解释的研究参考报告，每条分析都有数据依据。" |
| 展示免责声明 | 底部固定免责声明 | "合规边界：输出研究参考，不构成投资建议。" |
| 收尾 | — | "这就是我们的多视角金融研究 Agent：事件驱动、多因子验证、可解释可追溯。" |

## 时长控制

- 总时长：2分50秒（预留10秒缓冲）
- 重点：第3步四因子分析（50秒）——这是核心卖点
- 备选：若现场网络好，可在第1步后现场输入「机器人」展示实时分析（Agent 轨迹完整呈现）

## 录屏技术要点

- 分辨率：1920×1080，窗口最大化
- 提前关闭通知弹窗、清理桌面图标
- 预先打开所有页面，避免演示中途加载
- 录屏软件：OBS 或系统录屏，MP4 格式，≤50MB
