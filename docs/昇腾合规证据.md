## 二、昇腾原生算力跑通记录（GitCode Notebook 实测）

环境：`Linux + Python 3.11.14 + CANN 8.5.0 + NPU (ASCEND_VISIBLE_DEVICES=2)`

```
[3/4] 昇腾环境检测...
  计算框架: torch_npu | 设备: Ascend(torch_npu)
  OK 昇腾 NPU 可用 (昇腾原生算力已启用 (torch_npu))
[4/4] 运行真实金融分析 (低空经济, 离线规则模式)...
  OK 完成: 0.1s | 候选股 30 只 | 报告 692 字
```

关键事实：
- `torch.npu.is_available() == True`，协方差矩阵在昇腾 NPU 上计算（`torch.as_tensor(..., device="npu:0")`）；
- 昇腾加速模块 `src/ascend_accel.py` 提供三档后端自动切换：**MindSpore(昇腾) → torch_npu(昇腾) → numpy**，昇腾环境自动启用昇腾算力，本机无昇腾框架时降级 numpy（结果一致，与 `np.cov` 最大误差 < 1e-8）；
- 昇腾云模型调用（配 `ASCEND_API_KEY` 后）走 `api-ai.gitcode.com`，侧边栏实时显示成功率/延迟统计。

## 三、复现步骤（评审可验证）

**方式一：GitCode Notebook（推荐，已实测）**
1. 打开 GitCode → 我的 Notebook → 启动（资源规格选 **NPU**）；
2. 终端执行：
   ```bash
   git clone https://gitcode.com/zhichen1024/agent_finance.git
   cd agent_finance
   python setup_notebook.py
   ```
3. 观察输出：`计算框架: torch_npu | 设备: Ascend(torch_npu)` + `OK 昇腾 NPU 可用`，随后自动跑通真实金融分析。

**方式二：昇腾环境手动部署**
```bash
bash scripts/deploy_ascend.sh    # 安装 MindSpore(昇腾) + 依赖 + 配置 Key
python3 -c "from src.ascend_accel import backend_info; print(backend_info())"  # 期望 ascend_npu=True
```

**方式三：昇腾云 API 路径（无 NPU 硬件也可）**
```bash
echo 'ASCEND_API_KEY=你的Key' > .env
python3 -c "from src.pipeline import run_analysis; r = run_analysis('低空经济', use_llm=True, enrich_market=True); print('股票:', len(r['stock_results']), '报告:', len(r['report']), '字')"
```
