# 演示录屏脚本（3分钟）

> 补漏块6 交付: 完整演示分镜 + 话术。视频由用户在本地录制（无头环境无法录真实浏览器会话），本脚本提供精确分镜和预期画面。

## 总览

| 时间段 | 内容 | 关键画面 |
|--------|------|---------|
| 0:00-0:30 | 首页展示（翻转卡 + 渐变按钮） | 3D 翻转卡 hover 翻转、渐变按钮 hover 光效 |
| 0:30-1:00 | 点击预置热点 → 秒开结果 | demo_state 秒开（<3秒），Agent 轨迹 |
| 1:00-1:30 | 完整分析过程 | 脉冲加载器 + 进度条 |
| 1:30-2:00 | 结果页展示 | 影响链 / 四因子雷达 / 风险饼图 |
| 2:00-2:30 | 深色/浅色切换 + 响应式 | 霓虹开关切换、缩放演示 |
| 2:30-3:00 | 导出报告 + 总结 | 报告下载 + 免责声明 |

## 详细分镜

### 第1幕（0:00-0:30）首页
- **操作**: `streamlit run ui/app.py`，打开首页
- **画面**: 4 个 3D 翻转卡（低空经济/AI算力/机器人/新能源），鼠标悬停卡片翻转显示"✓ 悬停查看"
- **话术**: "我们的系统是事件驱动的金融研究 Agent。预置了 10 个热点主题，点击即可秒开分析结果。"

### 第2幕（0:30-1:00）秒开预置热点
- **操作**: 点击"分析 低空经济"
- **画面**: 跳转事件分析页，Agent 执行轨迹逐步显示（事件理解→产业链→假设→因子→风险→报告），右下角时间戳
- **话术**: "预计算结果秒开，避免现场网络波动。Agent 的执行轨迹完全透明可追溯。"

### 第3幕（1:00-1:30）实时分析
- **操作**: 输入"机器人"，点击渐变按钮"🚀 开始分析"
- **画面**: 脉冲加载器动画 + st.progress 进度条，分析中
- **话术**: "如果现场网络良好，我们也可以现场发起实时分析，展示完整的 Agent 工作过程。"

### 第4幕（1:30-2:00）结果页
- **操作**: 依次切到多因子分析页、风险分析页、研究报告页
- **画面**: 四因子柱状图 + 雷达图、综合排名、风险等级饼图、完整 Markdown 报告
- **话术**: "四因子多视角验证，风险分级清晰，最终输出可解释的研究参考报告。"

### 第5幕（2:00-2:30）主题切换 + 响应式
- **操作**: 侧边栏霓虹开关切深色模式；浏览器缩放演示移动端单列
- **画面**: 深色主题切换、移动端布局
- **话术**: "支持深色/浅色主题，响应式适配桌面/平板/移动端。"

### 第6幕（2:30-3:00）导出 + 总结
- **操作**: 研究报告页点"下载 Markdown"，展示免责声明
- **画面**: 下载文件名带时间和主题
- **话术**: "输出研究参考，不构成投资建议。这就是我们的多视角金融研究 Agent。"

## 录屏技术要点
- 分辨率 1920×1080，OBS 或系统录屏，MP4 ≤ 50MB
- 预置热点提前预热（demo_state 已生成），避免中途等待
- 移动端演示可用浏览器开发者工具的设备模拟
